## 我们在做什么

### 团队工作室（进行中）

一个像素风格的线上团队协作空间。BK、Marvis、CC 三方实时群聊，角色以像素手绘动画呈现。

| 维度 | 详情 |
|------|------|
| 前端 | Preact + Canvas 2D 像素网格渲染 |
| 后端 | Node.js + Express + WebSocket + SQLite |
| 角色 | CSS 像素方块手绘（支持独立动画与状态切换） |
| 状态 | 原型已完成，编码待启动 |
